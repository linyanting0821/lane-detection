# lane-detection
# 動機:
  製作自走車，能夠辨識車道
# 方法:  
  1.影像預處理：程式先將輸入影像縮放至固定大小，並轉換為灰階圖像。接著選擇感興趣區域（ROI），並應用透視變換將圖像從平面轉換為車道的正視圖。

  2.邊緣檢測：使用了Canny邊緣檢測來提取車道邊界。經過一系列的形態學操作（膨脹、模糊、腐蝕），來強化車道邊緣。

  3.霍夫變換：通過霍夫直線變換提取車道的直線。程式對識別出的直線進行過濾，選擇斜率合理的車道邊界線。

  4.顯示和輸出：顯示車道識別結果
# 優化
  1.過濾更精準的斜率：在過濾斜率時，我們可以根據車道線的斜率範圍來進行精確篩選，並將過濾條件更嚴格。例如，針對左側車道線，我們可以限制斜率在一個較窄的範圍內，避免選擇到不符合條件的直線。  
  2.補全未偵測到的車道線：當發生未偵測到車道線或是只偵測到其中一條，利用前一禎的斜率和截距模擬一條車道線
